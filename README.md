# DocuTimer Web — docutimer.com

The official marketing website for **DocuTimer: Expiry Reminders** for iOS.

Designed with the **"Ledger"** design system — black/white canvas, hairline cells, tabular numerals, and urgency indicated by tint and rail.

## Features
- **Design System Fidelity**: Direct port of `DocuTimerTheme.swift` tokens and `DocuTimerTypography.swift` rules.
- **Adaptive Theme**: Live Light and Dark mode switcher with `localStorage` persistence and automatic `prefers-color-scheme` support.
- **Interactive iOS App Simulator**: Live phone frame featuring the Today view, interactive household member filter chips, dynamic hero countdown, and real-time urgency rail badges.
- **Renewal Runway™ Calculator**: Interactive calculation tool demonstrating the 6-month passport travel validity cutoff and government backlog lead times.
- **Search Engine Optimization (SEO)**:
  - Structured Data: Schema.org `MobileApplication`, `FAQPage`, `WebSite`, `BreadcrumbList`.
  - OpenGraph & Twitter Cards with high-resolution app icon assets.
  - Comprehensive keyword architecture targeting passport renewals, driver's licenses, visas, insurance policies, and private document vaults.
  - Valid `sitemap.xml` and `robots.txt`.
- **Performance**: Zero external JavaScript frameworks. Ultra-fast vanilla HTML/CSS/JS with zero bundle overhead for 100/100 Google Lighthouse scores.
